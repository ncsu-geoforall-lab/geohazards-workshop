    Geohazard Change Detection for Emergency Management with GRASS

    FOSS4G NA 2026 workshop, Sacramento. 2026-11-02, 13:00-16:00, Room Bondi.

    Repeat lidar shows how wildfire and the storms that follow it reshape a watershed. A raw DEM of Difference (DoD) mixes that change with measurement error, co-registration offsets, and vegetation effects. In this workshop we build an uncertainty-aware change detection workflow in GRASS with the r.dem toolset and run it on Humbug Creek, California, which burned in the 2022 McKinney Fire and was hit four days later by a storm that dropped about 4 in of rain on the burn scar.

    The workshop is fully hands-on. Everything runs in a browser through GitHub Codespaces, or locally in the same container.

    Workshop site with rendered notebooks and slides: https://ncsu-geoforall-lab.github.io/geohazards-workshop/

    Learning objectives

    By the end of the workshop you will be able to:

    1. Compute a DoD between two lidar epochs and explain where it misleads.
    2. Measure and remove the horizontal and vertical offset between two surveys on stable terrain, and decide when a datum transform helps.
    3. Estimate a level of detection (LoD) and apply a spatially variable threshold instead of a single value.
    4. Organize multi-date elevation data with the GRASS temporal framework.
    5. Turn significant change into volumes and post-event change maps by burn severity and subwatershed, and export them for desktop GIS.

    Each notebook starts by loading a checkpoint, so you can rejoin at the start of any part. If you fall behind, open the next notebook and run all cells. It picks up the maps it needs from the checkpoints of the earlier parts, and you do not need to finish or close the notebook you were in.

    Getting started

    See SETUP.md. The short version is to click the Codespaces badge above and wait for the setup to finish, then open notebooks/00_setup_check.ipynb and run all cells.

    Prerequisites

    Some GIS experience and basic Python. Prior GRASS experience helps but is not required.

    Data

    Lidar from the USFS (2013) and USGS 3DEP (2022), Sentinel-2 imagery from 2022, and USGS NHD stream lines. Sources, collection dates, and datums are in data/README.md.
